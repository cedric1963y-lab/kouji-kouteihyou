利用規約

対象は iPhone アプリ「工事の工程表」（Bundle ID jp.koutei.app）です。最終更新: 2026年11月20日。

本アプリの利用には、Apple の標準使用許諾契約（Licensed Application End User License Agreement）が適用されます。

Pro（自動更新サブスクリプション）

  • サブスクリプショングループ: 工事の工程表 Pro
  • 月額: ¥100（1か月ごとに自動更新）
  • 年額: ¥1,000（1年ごとに自動更新）
  • 無料体験: 月額・年額とも、はじめての方は1週間無料（対象の Apple ID のみ）

表示価格は日本の価格（税込）です。実際に請求される金額は、購入画面に表示される金額です。

お支払いは購入を確定した時点で Apple ID に請求されます。無料体験の対象の場合は、無料期間が終わった時点で課金が始まります。無料期間が終わる24時間以上前に解約すれば請求されません。現在の期間が終わる24時間以上前に解約しない場合、同じ期間・同じ価格で自動更新され、更新料は期間が終わる前の24時間以内に請求されます。

管理と解約は、iPhone の「設定」> Apple ID >「サブスクリプション」から行えます。解約後も、その期間の終わりまでは Pro を使えます。返金は Apple の基準に従います。

無料プランと Pro の違い

無料プランでは、同時に2現場まで工程表を作れます。雨・遅れのずらし、空き確認、職種のひな形、画像で送るのは無料です。無料の画像には小さく「工事の工程表で作成」と入ります。

Pro では、現場の数の上限がなくなり、画像に屋号・会社名・連絡先を入れられ、アプリ名の表示が消え、A4横の PDF で送れます。

契約が終わっても、作った工程表は消えません。無料プランの範囲を超えて作った現場も、そのまま残ります。

免責

工程の日付と日数は、入力された内容と休みの設定（日曜・祝日・お盆・年末年始・土曜の扱い）をもとにした計算です。実際の工程と、元請さん・お客さんとの約束の最終確認は利用者が行ってください。
