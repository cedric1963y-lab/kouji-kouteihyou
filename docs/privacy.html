工事の工程表

プライバシーポリシー

対象は iPhone アプリ「工事の工程表」（Bundle ID jp.koutei.app）です。最終更新: 2026年11月20日。

工事の工程表（以下「本アプリ」）は、入力された現場名・工程・日付・節目・メモ・屋号や連絡先を、この iPhone の中だけに保存します。

  • アカウント登録はありません
  • 運営のサーバーへ、工程表・メモ・屋号・購入情報を送りません
  • 広告 SDK、解析 SDK は入れていません

収集する情報

開発者が利用者の情報を収集することはありません。入力した内容は、本アプリでの工程表の表示と、利用者が自分で操作した共有（LINE、メール、ファイルなど）にだけ使われます。共有した先での扱いは、共有先のサービスの方針に従います。

祝日

日本の祝日はアプリの中で計算しています。祝日を調べるための通信はしません。

トラッキングと広告

トラッキングはしません。広告識別子も、広告 SDK も使いません。このウェブページも、解析用のスクリプトや第三者への送信をしません。

購入

購入と契約の確認は Apple の App Store（StoreKit）が行います。本アプリは契約の有効期限だけを端末内に控えます。支払い情報を本アプリや開発者が受け取ることはありません。

バックアップと削除

iPhone のバックアップをオンにしている場合、Apple のバックアップに本アプリのデータが含まれることがあります。本アプリを削除すると、端末内のデータも消えます。

使わない権限

位置情報、カメラ、写真ライブラリ、連絡先、マイク、健康情報は使いません。
