工事の工程表

サポート

対象は iPhone アプリ「工事の工程表」（Bundle ID jp.koutei.app）です。最終更新: 2026年11月20日。

職人さん・一人親方のための工事の工程表アプリです。現場ごとの「いつからいつまで」と節目を横の帯で見て、雨や前の業者の遅れはタップでまとめてずらし、元請さん・お客さんに画像で送れます。アカウントはありません。

使い方

  1. 右下の「＋ 現場」から職種（外壁塗装・屋根・内装リフォーム・水回り・外構・新築（大工）・白紙）を選ぶと、工程がまとめて入ります。
  2. 帯をタップすると、始まりの日と日数を直せます。日曜・祝日・お盆・年末年始は日数に数えません。土曜は「設定」で全体、または現場ごとに選べます。
  3. 雨で中止になったら、上の日付をタップして「雨で中止」を選びます。その日にかかる工程は1日延び、後ろの工程は1稼働日うしろへずれます。
  4. 前の業者や材料の遅れは、工程をタップして「遅れた → ここから後ろをずらす」で日数を選びます。帯を長押ししてドラッグしても動かせます。
  5. 「何日から入れる？」と聞かれたら、上のカレンダーのボタン（空き確認）で日付と日数を選びます。ほかの現場名を出さない返事の文をコピーできます。
  6. 右上の共有ボタンから、元請さん向け・お客さん向けの工程表を画像にして LINE などで送れます。

無料と Pro

無料では、同時に2現場まで工程表を作れます。雨・遅れのずらし、空き確認、職種のひな形、画像で送るのは無料で使えます。無料の画像には、右下に小さく「工事の工程表で作成」と入ります。

Pro は月額 ¥100、または年額 ¥1,000 の自動更新サブスクリプションです（はじめての方は1週間無料）。現場の数の上限がなくなり、送る画像に屋号・会社名・連絡先を入れられ、アプリ名の表示が消え、A4横の PDF で送れます。解約しても、作った工程表は iPhone の中に残ります。広告はありません。

支払いや解約の条件は 利用規約 に書いてあります。購入の復元は、アプリの「設定」→「購入を復元」です。

データの扱い

工程表のデータは、この iPhone の中だけに保存します。運営のサーバーへは送りません。詳しくは プライバシーポリシー です。
